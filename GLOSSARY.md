# gamepad-wheel

A phone clipped to a gamepad steers; the gamepad does everything else; the PC merges both into one virtual Xbox controller.

## Language

**Gamepad Volante**:
The product's name as shown to the user, on both the PC program and the phone app. Code, repository, executable and Android application id are named `gamepad-wheel`.
_Avoid_: Girovolante (the working name on the design canvas), gamepad-wheel in user-facing text
